# Панель v3: инвентарь проверки

Проверить до выпуска:

- Каталог: создание, переименование, перенос, порядок, удаление с подтверждением, отмена, перезагрузка.
- Линии: прихожая и терраса независимы; новые линии коридора; запланированные выключатели недоступны.
- Состояния: нет ложных показаний при потере связи; удалённые исходные датчики не оставляют актуальные демопоказания.
- Привязки: новые, перенесённые и импортированные устройства требуют повторной проверки; неизменные ID сохраняют entity_id.
- Камеры: три исходных слота, запрос кадра вручную, без фонового опроса картинки, ошибка и закрытие до ответа.
- Инженерия: ворота, котёл, питание насоса только для наблюдения; ни одной команды исполнительным устройствам.
- Мастер-свет: только установленные световые линии с флагом включения; исключает инженерное оборудование.
- Чистый запуск: новая база v3, пустые привязки, отсутствие фото и таблицы миграций. Копии: только v3; несовместимые форматы отклоняются.
- Регрессия: SQLite, CSRF, секреты, фото, обе темы, ожидание, демокоманды, 3D, пять разделов.
- Экраны: 1440×900, 1280×800, 375×900; отсутствие горизонтального переполнения.

Проверки настоящего дома, моделей приводов, котла, Яндекса и Tapo не заменяются мок-тестами.

## Результаты

- Каталог JSON: PASS. Постоянные ключи, переименование, порядок, типы, запрет дубликатов, сброс verified при импорте v3, блокировка planned и подмены возможностей.
- Backend: чистая инициализация v3, SQLite после перезапуска; старые и неизвестные форматы отклоняются, база не перезаписывается и не мигрирует.
- Безопасность: PASS. CSRF, разделение visitor-профилей, отсутствие секретных файлов в HTTP, удаление access_token из состояний камеры.
- Команды: PASS. Чтение состояния, подтверждение, идемпотентность, авторизация и тайм-аут; перенос снимает verified, переименование / порядок сохраняют привязку.
- Инженерия: PASS. С проверенными сущностями команды воротам, котлу, насосу и камере всё равно отклоняются. Неизвестное положение ворот не превращается в «закрыто». В интерфейсе нет инженерных переключателей.
- Камеры: PASS на имитации HA. Кадр запрашивается вручную, декодируется браузером; закрытие до ответа не возвращает изображение в закрытый диалог. Нет выдуманной трансляции и передачи токена камере в браузер.
- Браузер Chromium: создание линии, подтверждение демокоманды, перенос, переименование, порядок, reload, отмена удаления и подтверждённое удаление.
- Прихожая / терраса: разные карточки и независимые состояния; левая линия даёт питание RGB. Правый канал доступен из отдельной карточки террасы.
- JSON v3 через UI: экспорт всего каталога без токена; импорт снимает verified и сохраняет entity_id; неизвестный формат отклоняется.
- Визуально: пять разделов на 1440×900, 1280×800 и 375×900; обе темы главной, мобильный каталог и форма. Горизонтального переполнения и ошибок JavaScript не обнаружено.
- Навигация на длинных страницах закреплена внизу. Содержимое можно прокручивать.
- Ожидание / пробуждение: проверены. Three.js в покое: 2 → 2 кадра за 1,5 секунды.
- Runtime: установка зависимостей локального release через npm ci проверена на Linux; запуск Windows .cmd на настоящем Windows в этой среде не выполнялся.
- Развёрнутое приватное превью: каталог и инженерные карточки доступны; сохранение темы и reload проверены в обычном окне и opaque sandbox iframe, ошибок JavaScript нет.
- Сводка климата следует зоне датчика, не старому ID: перенос исходного датчика убирает его из показаний прежней комнаты; новый проверенный датчик соответствующей зоны работает в сводке.

Внешние устройства и реальные домашние интеграции ещё не подключены. Использованные имитации и их данные не входят в установочный архив.
