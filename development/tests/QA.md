# Приёмка этапа до подключения в доме

## Проверяемые требования

- Сохранение темы, избранного, порядка, ожидания, ночного и компактного режима: изменить через UI, дождаться «Сохранено», reload, проверить значения. Backend: перезапустить процесс и проверить ту же базу.
- Фото: выбрать, явно сохранить локально, reload; заменить, сбросить, reload. Повреждённое изображение не должно уничтожать старое. В превью постоянное фото запрещено.
- Полный экран: пользовательская кнопка, fullscreenElement, выход; корректное сообщение, если iframe запрещает API.
- Технический раздел: отдельная точка входа, все вкладки, состояние подключения, фильтр привязок, редактирование названия, непроверенный entity_id, ошибка проверки неизвестной сущности.
- Backup: download через кнопку, JSON без токена и состояний; import, demo mode, сброс verified; повреждённый JSON сохраняет прежние настройки.
- Live без подключения: ни демотемператур, ни «закрытой» двери; переключатели, RGB и мастер заблокированы; демосимулятор отключён.
- Демо: команда с подтверждением, ошибка/повтор, RGB с питанием, ожидание, wake без команды, 3D lazy loading.
- HA adapter на отдельном mock-сервере: state readback, идемпотентность, ошибки авторизации, тайм-аут, allowlist, блокировка насоса/планируемой ленты/станции, дубликаты entity_id.
- Сервер: защищённые изменения, запрет Origin, секретных файлов и SQLite через HTTP; изоляция X-Visitor-Id в превью.
- Визуально: главная dark/light desktop 1280+, настройки, технические вкладки, live unknown, 3D, mobile375 без горизонтального overflow.
- Отрицательные сценарии: ошибка хранилища, сломанная копия, недоступный HA, отказ подтверждения команды.

Реальные устройства, Windows cmd и физический kiosk-экран не считаются проверенными в этой среде.

## Результат проверки

- Backend integration suite: PASS. Перезапуск SQLite, CSRF, Origin, запрет секретных файлов, проверенные привязки, дубликаты, state readback, тайм-аут, авторизация, исключённые команды.
- Приватное превью: изоляция двух visitor-профилей, запрет домашнего HA и постоянного фото в облаке.
- Браузер Chromium: настройки после reload, фото save/reset/corrupt input, переименование линии, непроверенные bindings, отказ проверки без HA, export/import, сброс verified и ошибки JSON.
- Полный экран: вход и выход через UI.
- Live без HA: температура «—», дверь «Нет данных», мастер и неизвестные каналы недоступны, симулятор заблокирован.
- HA mock + браузер: два физически условных канала, температура/влажность/дверь/дым, отправка и наблюдение состояния, master, потеря/восстановление связи.
- Ожидание включается даже при опросе live каждые 5 секунд. Первое касание только пробуждает.
- Деморегрессия: ошибка с сохранением подтверждённого состояния, повтор, RGB только с питанием.
- Three.js: загружается только после вкладки модели, в покое счётчик отрисовки 2 → 2 за секунду.
- Видимость: desktop 1440×900 и 1280×800, mobile375×900, обе темы, настройки и технические вкладки. Горизонтального overflow и runtime errors не обнаружено.
- Изменения состояния перерисовываются без повторной анимации появления, чтобы опрос не вызывал мигание.
- Deployed preview: получение/сохранение/reload/export/import проверены в обычном и opaque sandbox iframe.
- Локальный release: npm ci с отдельным runtime package успешно выполнен в Linux. Windows launcher проверен по коду, но не исполнялся в Windows.
