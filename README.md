# Home Panel

Панель управления домом с 3D-планировкой, работающая как приложение Home Assistant OS на том же системнике. Порт веб-интерфейса — **8090**; тема, избранное и привязки сохраняются в SQLite в `/data/homepanel`.

Текущая версия: **1.1.0**. Добавлена расширяемая модель логических устройств поверх прежних каналов и привязок. Тема, фото, рабочий режим и проверенные entity_id сохраняются; перед миграцией прежний JSON записывается в страховочную таблицу той же SQLite-базы. Камера остаётся на WebRTC с HLS как резервом, порт остаётся 8090. Проверка структуры репозитория: `node tests/repository-layout.mjs`.

## Расширяемые устройства

В панели открой **Настройки → Технический раздел → Устройства**. Здесь можно объединять температуру, влажность и батарейку одного датчика, менять название прибора, выбирать основную комнату и разгруппировать без удаления сущностей. Вкладка **Каталог** по-прежнему редактирует отдельные каналы, **Привязки** связывают их с HA.

Новый канал получает представление без размещения на плане. В «Обзоре» связанные показания собраны в одну карточку. Типы «Карниз» и «Робот-пылесос» пока предназначены только для наблюдения, без команд; автоматический импорт и новый редактор плана будут отдельными этапами. Подробный контракт, миграция и ограничения: [DEVICE_MODEL.md](DEVICE_MODEL.md).

При обновлении не удаляй приложение. Сначала сделай резервную копию HA с включённым Home Panel, затем обнови установленное приложение и перезагрузи страницу панели. Перенастраивать HA и повторно подтверждать прежние привязки для этой версии не требуется.

## Установка из этого репозитория

1. Открой **Настройки → Приложения → магазин / Установить приложение**.
2. Нажми **⋮ → Репозитории**.
3. Добавь `https://github.com/Leg1onary/home_panel`.
4. Найди приложение **Home Panel**, открой его и нажми **Установить**.
5. После сборки включи **Запуск при загрузке**, затем нажми **Запустить**.
6. Открой веб-интерфейс кнопкой приложения либо по адресу `http://<IP-Home-Assistant>:8090`.

Это стандартная схема подключения стороннего репозитория приложений HA ([официальное руководство](https://developers.home-assistant.io/docs/add-ons/repository/)). Для этого способа не нужны SCP, установка через `install-home-panel.sh`, изменение `configuration.yaml` или добавление персонального токена в браузер.

## Первое подключение устройств

Готовый профиль дома содержит до 33 привязок, две рабочие линии ванной, батарейки и Дуо Макс. После обновления до 1.0.7 открой **Настройки → Технический раздел → Связь → «Подтвердить привязки и включить HA»**, чтобы проверить заменённые климатические соответствия. Известные прежние Xiaomi-привязки климата мигрируют на Яндекс; прочие ручные соответствия и оформление сохраняются. Подробности и приёмка: [HOUSE_PROFILE.md](HOUSE_PROFILE.md).

Открой настройки панели → **Технический раздел → Связь**, выбери реальные состояния Home Assistant. Затем во вкладке **Привязки** загрузи сущности и проверь соответствие каждой линии перед разрешением управления.

Доступ к HA выполняется сервером через автоматически выданный Supervisor token ([документация API](https://developers.home-assistant.io/docs/add-ons/communication/)). Панель предназначена только для доверенной домашней сети и не имеет отдельной пользовательской авторизации; не пробрасывай порт 8090 в интернет.

## Обновления и сохранение

В версии 1.0.3 нажатие «Двор» открывает живое HLS-видео через Home Assistant. Сначала привяжи установленную камеру двора к проверенной сущности `camera.*` и включи рабочий режим панели. В окне просмотра есть остановка, повторный запуск, полный экран и снимок; закрытие окна прекращает просмотр. Видео с реальной камеры в облачном превью не показывается.

При обновлении сохраняй установленное приложение: не удаляй и не устанавливай заново ради обновления. Хранилище `/data` предоставляется HA для постоянных данных приложения ([описание конфигурации](https://developers.home-assistant.io/docs/add-ons/configuration/)); делай резервные копии с включённым Home Panel.

Первую Docker-сборку и работу контейнера необходимо проверить на HA OS. Серверный runtime проверен на Node.js 22; полная инструкция и ограничения перечислены в [INSTALL.md](INSTALL.md).

## Исходники и тесты

Каталог `development/` содержит исходники, а `home_panel/` остаётся готовым пакетом для HA OS. Для сборки и 13 наборов тестов: `cd development && npm ci && npm test`; в `.qa` создаются только локальные тестовые сборки, они не устанавливаются в HA. Приёмка модели: [QA-device-model.md](development/tests/QA-device-model.md).
